# SISPARK — Sistem Informasi Smart Parking by Axon 

## 1. Proses Bisnis

Proses bisnis SISPARK dimulai ketika pengendara ingin mencari tempat parkir. Sistem menampilkan informasi ketersediaan slot parkir melalui peta berbasis web. Sensor IoT mendeteksi status slot parkir dan mengirimkan data ke server agar informasi dapat diperbarui. Pengendara dapat memilih slot yang tersedia dan mencoba melakukan reservasi. Pengelola parkir dapat memantau kondisi slot melalui ringkasan okupansi.

## 2. Masalah

Pengendara sering mengalami kesulitan mengetahui ketersediaan tempat parkir secara langsung sehingga harus berkeliling mencari slot kosong. Hal ini membuang waktu dan bahan bakar serta berpotensi menyebabkan kemacetan. Di sisi lain, pengelola parkir membutuhkan informasi okupansi yang akurat dan terkini untuk memantau penggunaan area parkir.

## 3. Pelaku (Aktor)

- **Pengendara:** Melihat ketersediaan slot parkir dan memilih atau melakukan reservasi slot.

## 4. Solusi Awal

SISPARK merupakan website informasi parkir yang dirancang untuk membantu pengendara mengetahui ketersediaan slot parkir dan melakukan reservasi secara lebih mudah. Website terintegrasi dengan sistem sensor IoT untuk memperoleh informasi status slot parkir sehingga pengendara dapat menentukan pilihan sebelum tiba di lokasi.

Fitur utama yang direncanakan meliputi:
1. Menampilkan peta ketersediaan slot parkir.
2. Menampilkan status slot parkir kosong dan terisi.
3. Memungkinkan pengendara memilih dan melakukan reservasi slot yang tersedia.
4. Menampilkan konfirmasi reservasi kepada pengendara.

Pengembangan difokuskan pada website untuk pengendara dan tidak mencakup dashboard khusus operator parkir.
